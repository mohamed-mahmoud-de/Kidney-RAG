    Kidney-RAG is a retrieval-grounded lookup over indexed clinical guidelines. It is not a substitute for professional medical advice. Always consult a qualified clinician for patient-specific decisions.

    How it works

    1. 01

      Retrieve

      Hybrid search — MedEmbed semantic (0.7) fused with BM25 lexical (0.3) via RRF over 666 chunks.

    2. 02

      Gate

      Top-hit cosine ≥ 0.70 or the system refuses. Calibrated with a 0.10 gap between in-scope and out-of-scope on the eval set.

    3. 03

      Ground & cite

      LLM answers only from the retrieved text, in a fixed Recommendation / Excerpt / Citation format, with the chunk ID embedded.

    4. 04

      Verify

      Post-hoc claim extractor + verifier scores faithfulness and citation accuracy on every answer.
